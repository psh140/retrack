# 도메인 구매 가이드

작성일: 2026-07-29
관련 문서: [`배포-체크리스트.md`](배포-체크리스트.md) — 2번 항목(도메인 구매)의 상세 설명

이 문서는 Retrack을 EC2에 배포하기 위해 도메인을 구매하고 EC2에 연결하기까지의 절차를 정리한다.
**구매·결제는 본인 계정으로 직접 진행해야 한다.**

---

## 1. 어디서 살 것인가

| 등록기관 | 대략 연간 비용 | 장점 | 단점 |
|---|---|---|---|
| **Route 53** (AWS) | `.com` $15 내외 / `.dev` $12~16 내외 | AWS 콘솔 한 곳에서 관리, DNS 연동이 가장 단순 | 최저가는 아님 |
| Cloudflare Registrar | 원가 수준 (마진 없음) | 가장 저렴, 갱신가 인상 없음 | Cloudflare DNS를 써야 함 (AWS와 분리 관리) |
| 가비아 / 후이즈 | `.com` 2만원 내외 | 한국어 지원, 국내 결제 편의 | 첫해 할인 후 갱신가가 오르는 경우가 많음 |

**추천: Route 53.** 연 몇 달러 차이보다, EC2·Elastic IP와 같은 콘솔에서 A 레코드를 바로 연결할 수 있는
편의가 크다. 포트폴리오 목적이라면 관리 지점을 늘리지 않는 편이 낫다.

가격은 수시로 바뀌므로 결제 전 콘솔에서 실제 금액을 확인할 것.

---

## 2. 도메인 이름 정하기

공공기관·SI 취업용 포트폴리오라는 목적을 고려한 기준이다.

- **이력서에 적고 말로 부를 수 있어야 한다** — 하이픈·숫자·축약은 피한다
- 프로젝트명이 그대로 들어가는 게 가장 명확하다 (`retrack.dev`, `retrack.kr` 등)
- 이미 팔린 경우: `retrack-app`, `retrackhq`, `useretrack` 같은 변형보다 TLD를 바꾸는 편이 깔끔하다

**TLD 선택 시 주의 — `.dev`는 HTTPS가 필수다**

`.dev`는 브라우저 HSTS 프리로드 목록에 등록된 TLD라, **HTTP 접속이 브라우저 단에서 차단된다.**
인증서를 발급하기 전에는 `http://도메인`으로 동작 확인이 아예 불가능하다.

- 배포 검증을 단계적으로(HTTP 먼저 → HTTPS 나중에) 하고 싶다면 `.com` / `.kr`이 편하다
- `.dev`를 쓴다면 Certbot 인증서 발급까지 끝낸 뒤에 도메인으로 접속을 시도해야 한다
- 인증서 발급 전 동작 확인은 `http://<Elastic IP>` 로 하면 된다

## 3. Route 53 구매 절차

1. AWS 콘솔 → **Route 53** → 좌측 **Registered domains** → **Register domains**
2. 원하는 도메인 입력 후 검색 → 사용 가능하면 장바구니에 담기
3. 등록 기간 선택 (기본 1년) — **자동 갱신은 켜두는 것을 권장**한다.
   만료되면 도메인을 잃고 이력서 링크가 죽는다
4. 등록자 연락처 정보 입력
   - **개인정보 보호(Privacy protection)는 반드시 활성화**한다.
     끄면 이름·주소·이메일·전화번호가 WHOIS로 전 세계에 공개된다.
     `.kr` 등 일부 TLD는 보호를 지원하지 않으니 이 경우 공개를 감수할지 판단해야 한다
5. 약관 동의 후 결제
6. **등록 완료까지 최대 3일** 걸릴 수 있다(보통 수십 분~수 시간).
   등록 확인 이메일의 인증 링크를 누르지 않으면 도메인이 정지되므로 메일함을 확인할 것

구매가 끝나면 해당 도메인의 **호스팅 영역(Hosted zone)이 자동 생성**된다.
호스팅 영역은 도메인 등록비와 별도로 **월 $0.50**가 과금된다 (쿼리 요금은 이 규모에서 무시 가능).

## 4. EC2 연결 (A 레코드)

도메인 구매 후, EC2와 Elastic IP가 준비되면 진행한다.

1. Route 53 → **Hosted zones** → 구매한 도메인 선택
2. **Create record**
   - Record name: 비워둠 (루트 도메인 `retrack.dev`)
   - Record type: **A**
   - Value: **EC2의 Elastic IP**
   - TTL: 300
3. `www`도 쓰려면 레코드를 하나 더 만든다
   - Record name: `www`
   - Record type: **A** (또는 루트를 가리키는 CNAME)
   - Value: 동일한 Elastic IP

**반드시 Elastic IP를 쓸 것.** EC2 기본 공인 IP는 인스턴스를 중지·시작하면 바뀌어서
A 레코드가 죽은 IP를 가리키게 된다.

**전파 확인**

```bash
dig +short retrack.dev
# Elastic IP가 출력되면 연결 완료

nslookup retrack.dev
```

TTL 300 기준으로 보통 몇 분 내에 반영된다. 캐시 때문에 늦어 보이면 다른 네트워크(모바일 데이터)에서 확인한다.

## 5. 도메인 확정 후 이어지는 작업

도메인이 정해지면 코드 쪽에서 아래 작업이 풀린다 (배포 체크리스트 1-3, 4번).

- `frontend/nginx.conf` — `server_name _;` → 실제 도메인으로 변경
- `frontend/nginx.conf` — 443 서버 블록 + 인증서 경로 추가, HTTP → HTTPS 리다이렉트
- `docker-compose.prod.yml` — 443 포트 매핑과 인증서 볼륨 마운트 추가
- Certbot으로 Let's Encrypt 인증서 발급 및 자동 갱신 설정

**참고 — AWS Certificate Manager(ACM)는 이 구성에서 쓸 수 없다.**
ACM 인증서는 ALB·CloudFront·API Gateway에만 붙일 수 있고, EC2 안에서 직접 돌리는 Nginx에는
설치할 수 없다. EC2 단독 구성이므로 Let's Encrypt + Certbot을 쓴다.

## 6. 비용 요약 (월 기준, 대략치)

| 항목 | 비용 |
|---|---|
| 도메인 등록 | 연 $12~16 → 월 $1~1.5 |
| Route 53 호스팅 영역 | $0.50 |
| EC2 t3.small | $15 내외 |
| Elastic IP (퍼블릭 IPv4) | 시간당 $0.005 → 월 $3.6 내외 |
| Let's Encrypt 인증서 | 무료 |

**Elastic IP는 인스턴스 연결 여부와 무관하게 과금된다.** 2024년 2월부터 AWS는 모든 퍼블릭 IPv4
주소에 요금을 부과하며, 연결돼 있다고 무료가 되지 않는다. 프리티어 계정은 12개월간 월 750시간이
무료이므로 그 기간에는 청구되지 않을 수 있다. 정확한 단가는 AWS 요금 페이지에서 확인할 것.

포트폴리오 운영 목적이면 월 $20 내외를 예상하면 된다.
채용 시즌에만 켜둘 계획이라면 EC2를 중지해 인스턴스 요금은 줄일 수 있지만,
**Elastic IP와 EBS 볼륨은 인스턴스가 멈춰 있어도 계속 과금**되므로 "중지 = 0원"은 아니다.
