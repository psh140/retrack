# Retrack 프론트엔드 — 에이전트 작업 지침

**작업 전에 `frontend/CLAUDE.md`를 읽을 것.** 이 디렉터리의 규칙은 전부 그 문서에 있다.

| 섹션 | 내용 |
|---|---|
| 디자인 시스템 | 색상·타이포·컴포넌트 규칙 — **임의 디자인 금지** |
| 검색 기능 | 목록 페이지 검색·필터 구현 패턴 |
| 주석 규칙 | 파일 역할 설명 + `@since` / `@modified` |
| 기술 스택 결정 사항 | 상태 관리·라우팅·CORS 처리 방식과 그 근거 |
| 페이지 목록 | 경로별 페이지와 접근 권한 |
| 개발 현황 | 1~7단계 + UI 일관성 개선 완료 내역 |
| 트러블슈팅 | 실제 부딪힌 문제와 해결 |

## 이것만은 먼저

- **React 18 함수형 컴포넌트 + Hooks만 사용한다.** 클래스형 컴포넌트 금지
- **디자인은 기존 디자인 시스템을 따른다.** 색상·간격·컴포넌트 스타일을 임의로 정하지 않는다
- **API 호출은 `src/api/index.js`에 모은다.** 컴포넌트에서 axios를 직접 부르지 않는다
- **JWT는 axios 인터셉터가 자동 첨부한다.** 401 응답이면 localStorage를 비우고 `/login`으로 보낸다
- **에러를 api 레이어에서 삼키지 않는다.** throw해서 컴포넌트가 catch하고 화면에 표시한다
- 모든 페이지에 로딩 상태와 에러 상태 UI를 포함한다
- 새 페이지를 만들면 `App.jsx` 라우팅 등록을 빠뜨리지 않는다 (전 페이지 `lazy()` 코드 스플리팅 적용 중)

전역 규칙은 저장소 루트의 `AGENTS.md`에 있다.
